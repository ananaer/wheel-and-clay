# Wheel & Clay 宣传素材

- [全流程演示片](wheel-and-clay-intro.mp4)：V7，41秒，1920×1080，60fps。
- [分享封面](wheel-and-clay-poster.jpg)：仓鼠把 W 拉回字列后的完成构图。

官方点阵仓鼠拉住一根细绳：第一次没拉动，换个支点再把落单的 W 拽回去。镜头在受力时推近，成功后回到完整标题。随后展示自由塑形、另选挑战、实际78%成绩、施釉、收藏、复制专属链接和打开同件3D陶器。

这是剪辑后的产品演示。自由塑形的指针按本次真实鼠标事件复现；关键按钮补有示范指针与轻反馈，落点对应真实界面。挑战塑形来自原速连续录像，使用键盘，画面明确显示键盘提示。自由创作与挑战是两件不同作品；共享页真实拖动后停留。不是一镜到底实录，也不代表当时真实仓鼠正在跑。全片保留模拟来源与独立社区身份。

音乐来自项目原创 Wood & Light，另配原创细绳、落脚和轻点击音效。品牌素材来源见[BRAND-ASSETS.md](../BRAND-ASSETS.md)。视频不代表 Squeekchain 官方出品、背书或审批通过。
