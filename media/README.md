# Wheel & Clay 宣传素材

- [全流程演示片](wheel-and-clay-intro.mp4)：V6，37秒，1920×1080，60fps。
- [分享封面](wheel-and-clay-poster.jpg)：排字归位后的完成构图。

细金刮片把错位的活字整理成 Wheel & Clay；最后一个 y 小小回头，再被轻推归正。随后展示两种创作路径：自由塑形，以及选题、挑战、实际78%成绩、施釉、作品卡、复制专属链接和打开同件3D陶器。

这是剪辑后的产品演示：实际浏览器画布录像保持原速，配合真实界面截图与镜头调度；自由与挑战是不同作品。共享页按需渲染，实际拖动后停留。不是一镜到底实录，也不代表当时真实仓鼠正在跑。全片保留模拟来源与独立社区身份。

音乐来自项目原创 Wood & Light，另配原创排字与木质轻敲音效。品牌素材来源见[BRAND-ASSETS.md](../BRAND-ASSETS.md)。视频不代表 Squeekchain 官方出品、背书或审批通过。
